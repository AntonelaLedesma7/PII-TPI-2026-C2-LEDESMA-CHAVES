# ⚡ SmartGrids — Sistema de Monitoreo Energético
## **Trabajo Práctico Integrador | Programación II (UNGS)**

Implementación del sistema `SmartGrids` en Java aplicando principios de la Programación Orientada a Objetos.

## ✨ Descripción General 
**SmartGrids** es un sistema integral desarrollado en Java para la gestión, supervisión y análisis en tiempo real de redes de generación eléctrica. La plataforma permite monitorear tanto instalaciones de energías renovables (**Solar**, **Eólica**, **Hidráulica**) como no renovables (**Térmica**), procesando métricas horarias de generación, niveles de emisión de CO₂, registros de incidencias y cumplimiento de cuotas operativas.

## 🚀 Características Principales
* 🏭 **Arquitectura:** Soporte extensible para plantas Solares, Eólicas, Hidráulicas y Térmicas con reglas de negocio y cálculo de cuotas diferenciadas. 
* 🧬 **Diseño POO Robusto:** Aplicación de herencia, clases abstractas, encapsulamiento y polimorfismo.
